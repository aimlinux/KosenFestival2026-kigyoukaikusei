# 文化祭教室用 参加者カード作成

文化祭の教室内で使うために作った、人物カード作成アプリです。
同じ教室の端末であれば、誰でもブラウザから使えます。

## できること

1. 名前・クラス・ニックネーム入力
2. 趣味を1〜6個まで追加・削除
3. ハッシュタグの自動生成
4. リアルタイムプレビュー
5. テーマ変更
6. A5横／縦の切り替え
7. プロフィールをローカルブラウザに保存
8. 保存済みプロフィールの読み込み・削除
9. 高解像度PNG出力
10. ブラウザ印刷でA5実寸印刷

## ローカルサーバーで起動する方法

Windows の場合:

1. このフォルダで `start_local_server.bat` をダブルクリック
2. 自動でブラウザが開き、 `http://localhost:8000` で起動します
3. そのページを教室内の端末で表示して使います

手動で起動する場合:

```bash
cd このフォルダ
py -m http.server 8000
```

または

```bash
python -m http.server 8000
```

## 教室内専用の注意

- このアプリはインターネット公開向けではなく、ローカルサーバーで使う前提です
- 外部サーバーにデータを送信しません
- 保存データは各ブラウザの `localStorage` に残ります
- 同一端末・同一ブラウザ内での利用を前提にしています

## 印刷

「A5印刷」を押して、印刷ダイアログで以下を推奨します。

- 用紙：A5
- 拡大縮小：100% / 実際のサイズ
- 余白：なし
- 背景のグラフィック：ON

印刷CSSはA5横を基準にしています。
