# 文化祭教室用 参加者カード作成

文化祭の教室内で使うために作った、人物カード作成アプリです。
同じ教室の端末であれば、サーバーを起動したPCと同じネットワークから使えます。

## できること

1. 名前・クラス・ニックネーム入力
2. 趣味を1〜6個まで追加・削除
3. サーバーに保存された趣味ランキングの表示・クリック入力
4. サーバー未接続時のサンプルランキング表示・クリック入力
5. ハッシュタグの自動生成
6. リアルタイムプレビュー
7. テーマ変更
8. A5横／縦の切り替え
9. プロフィールをローカルブラウザに保存
10. 保存済みプロフィールの読み込み・削除
11. 高解像度PNG出力
12. ブラウザ印刷でA5実寸印刷

完成イメージには実際のパブ店内写真を使用しています。写真は [assets/README.md](./assets/README.md) に記載の CC0 素材です。

## ローカルサーバーで起動する方法

Windows の場合:

1. このフォルダで `start_local_server.bat` をダブルクリック
2. 自動でブラウザが開き、 `http://localhost:8000` で起動します
3. サーバーを起動したままにして、教室内の端末からPCのIPアドレスでアクセスします

手動で起動する場合:

```bash
cd このフォルダ
py server.py
```

または

```bash
python server.py
```

## 教室内専用の注意

- このサーバーは教室内の信頼できるネットワークだけで使い、インターネットへ公開しないでください
- プロフィール本体は各ブラウザの `localStorage` に残ります
- 趣味ランキング用には趣味名とプロフィールIDのみを起動PC上のSQLiteデータベースへ保存します。氏名などのプロフィール情報は送信しません
- ランキングデータは Windows では `%LOCALAPPDATA%\KosenFestival2026\hobby-ranking.sqlite3` に保存されます
- ランキングはサーバーを使う端末間で共有され、プロフィールを保存・編集・削除すると同期されます
- サーバー未接続時には画面に「仮データ」と明記したサンプルランキングを表示します。クリックして趣味入力に使えますが、実際のランキングデータとしては保存されません
- 起動PCのデータベースファイルをバックアップすると、ランキングを引き継げます

## 印刷

「A5印刷」を押して、印刷ダイアログで以下を推奨します。

- 用紙：A5
- 拡大縮小：100% / 実際のサイズ
- 余白：なし
- 背景のグラフィック：ON

印刷CSSはA5横を基準にしています。
