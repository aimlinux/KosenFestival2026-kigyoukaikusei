# Person Card Studio

人物の「名前・クラス・ニックネーム・趣味（1〜6個）・隠れた特技」を入力して、
参考画像の雰囲気に近い人物カードを作成するブラウザアプリです。

## できること

1. プロフィール入力
2. 趣味を1〜6個まで追加・削除
3. ハッシュタグの自動生成
4. リアルタイムプレビュー
5. テーマ変更
6. A5横／縦の切り替え
7. プロフィールをブラウザ内に保存
8. 保存済みプロフィールの読み込み・削除
9. 高解像度PNG出力
10. ブラウザの印刷機能からA5実寸印刷

## 起動

`index.html` をChrome / Edgeなどで開くだけで使用できます。

サーバーは必須ではありません。

## データについて

プロフィールはブラウザの `localStorage` に保存されます。
別PC・別ブラウザとは共有されません。

## 印刷

「A5印刷」を押して、印刷ダイアログで以下を推奨します。

- 用紙：A5
- 拡大縮小：100% / 実際のサイズ
- 余白：なし
- 背景のグラフィック：ON

印刷CSSはA5横を基準にしています。
